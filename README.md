## GL Optimizer Beta Manual (v1.0.1)

### Overview
GL Optimizer is a lightweight Windows Optimizer designed to maximize your PC’s gaming performance especially when using GameLoop emulation. Leveraging intelligent presets and system recommendations, it fine tunes graphics, network, and operating system settings to deliver smoother frame rates and lower latencies.

### Key Features

1. **Auto-Recommendation Engine**  
   - Scans your hardware and software configuration.  
   - Suggests optimal settings profiles tailored to your GPU, CPU, memory, and network latency.

2. **Game Loop Optimization**  
   - Offers customizable presets specifically for most popular Android games via Game Loop.  
   - Adjust resolution, frame limits, and resource allocation to match your preferences.

3. **Windows 10/11 Tuning**  
   - Addresses known performance regressions in Windows 11 UI and background services.  
   - Disables harmless but resource-consuming features (e.g., animations, telemetry, indexing) to reclaim CPU and memory.
   - Provides a one-click “Recommended” preset to apply the most effective tweaks safely.

4. **DNS & Network Latency Management**  
   - Tests and lists several public DNS providers ranked by response time.  
   - Automatically applies the lowest-latency DNS to reduce in-game ping.

5. **NVIDIA Profile Manager**  
   - Installs and activates NVIDIA Control Panel profiles optimized for Game Loop.  
   - Fine-tunes 3D settings such as image sharpening, power management mode, and low-latency mode.

6. **Essential Gaming Software Installer**  
   - Curated list of must-have utilities,
   - One-click download and silent installation for seamless setup.

7. **Uninstall & Registry Cleaner**  
   - Detects non-essential applications that may impact performance.  
   - Performs root-level uninstalls and scans the registry for residual files and folders.

### Getting Started
1. **Launch GL Optimizer** from the desktop shortcut or Start Menu.  
2. On first run, **allow system scan** to detect hardware and software details.  
3. Review the **Auto-Recommendation** summary and click **Apply** to set the baseline profile.  
4. Navigate through each section via the left-hand menu to customize further:
   - **Game Loop**: Tweak resolution, FPS cap, and resource limits.
   - **Windows**: Enable/disable recommended system tweaks.
   - **DNS**: Benchmark and switch to the fastest server.
   - **NVIDIA**: Load or modify GPU profiles.
   - **Installer**: Download and install essential runtime components.
   - **Cleaner**: Uninstall unwanted apps and clean registry.

5. **Reboot recommended** after applying major changes to ensure full effect.
